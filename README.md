# Pharmaceutical Company Analysis Dashboard

## Project Overview

An interactive Power BI dashboard developed to analyse and compare the financial performance of leading pharmaceutical companies, focusing on revenue, R&D expenditure, and R&D expenditure as a percentage of revenue.

## Objectives

* Compare revenue across pharmaceutical companies.
* Analyse R&D investment and spending patterns.
* Calculate R&D expenditure as a percentage of revenue.
* Present financial insights through interactive visualizations.

## Tools Used

* Microsoft Power BI
* Microsoft Excel
* DAX (Data Analysis Expressions)

## Key Features

* KPI cards for revenue and R&D expenditure.
* Company-wise revenue and R&D comparison charts.
* R&D expenditure as a percentage of revenue.
* Interactive filters for exploring company data.

## Files Included

* `Pharma_Company_Analysis.pbix` — Power BI report.
* `Pharma_Company_Analysis.xlsx` — Dataset.
* `dashboard_preview.png` — Dashboard screenshot.

## How to Use

1. Download the Power BI `.pbix` file.
2. Open it using Power BI Desktop.
3. If prompted, update the Excel data source path.
4. Refresh the data if required and explore the report.

## Data Sources and Disclaimer

Financial information should be verified against the respective companies' official annual reports. Comparisons may be affected by differences in reporting periods, currencies, and business segments.

This project is intended for educational and portfolio purposes.
